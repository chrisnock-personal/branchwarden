Use it from the command line or an AI agent

The branchwarden command line, and its MCP server for agents such as Claude Code and Claude Desktop. Paste your token when login asks for it: it's kept in your computer's keychain, not in a file or your shell history.

  1. Install it (Python 3.10 or later):
    pipx install "branchwarden-cli[mcp] @ git+https://github.com/chrisnock-personal/branchwarden#subdirectory=cli"
  2. Sign in{% if connect.fingerprint %}, trusting this server's own certificate by its fingerprint{% endif %}:
    branchwarden login --url {{ connect.url }}{% if connect.fingerprint %} --fingerprint {{ connect.fingerprint|replace(':', '') }}{% endif %}
  3. Add it to Claude Code (or see the CLI's README for Claude Desktop):
    claude mcp add branchwarden -- branchwarden mcp

Then try branchwarden me, or ask your agent what's waiting on you. For scripts and CI, set BRANCHWARDEN_URL={{ connect.url }} and BRANCHWARDEN_TOKEN{% if connect.fingerprint %}, and BRANCHWARDEN_FINGERPRINT as above{% endif %} instead of signing in. Give an agent a read-only token unless it has to change things; even then, it asks before requesting reviewers on GitHub.
